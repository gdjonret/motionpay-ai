# MotionPay AI

**Ask. See. Move.** MotionPay helps beginners understand an exercise through conversation and a visual demonstration, then explore a structured next step with user-approved PayPal sandbox checkout.

## Problem and audience

Beginners often know an exercise name without knowing what the movement looks like. Finding a short, relevant demonstration can require navigating menus or searching through longer videos. MotionPay brings the question, demonstration, explanation, and optional program into one mobile experience.

## Working experience

Ask “Show me a squat.” The coach selects the catalog exercise and the app displays its credited demonstration and instructions. Ask about the muscles or technique using the conversation's recent context. “Make it slower” creates a half-speed version of the existing squat GIF; this is a timing transformation, not newly generated exercise footage.

For a request such as “I am a beginner and want to get stronger,” the AI can recommend Beginner Strength Essentials and explain why its equipment and schedule may be relevant. The user opens a review screen showing the current backend-owned price and program contents. PayPal sandbox handles explicit approval. FastAPI verifies and captures the payment before saving account-linked access in Supabase. Returning users open their existing program rather than buying it again.

The program has three sessions per week, distinct weekly focuses, and links to the exercise demonstrations. It is clearly marked as a prototype training template, not personalized or professionally reviewed coaching.

**AI-built plans, unlocked with PayPal.** Ask “Build me a 3-day dumbbell plan for glutes” and the coach offers the plan builder. The user chooses goal, level, days per week, equipment, and session length. Groq builds a 4-week plan with structured output whose exercise IDs are restricted to the 302-exercise library; the backend validates session counts, exercise counts, and IDs, and falls back to deterministic rules if the AI is unavailable. The server sets the price ($3.99 + $1 per weekly session) and stores the plan. Week 1 is a free preview. Weeks 2–4 unlock through the same reserved, idempotent PayPal Orders v2 sandbox checkout: the PayPal `custom_id` binds each order to the user and plan, and capture amount, currency, and plan are verified before the plan is unlocked atomically in Supabase.

## AI and developer tools

- **Groq / openai/gpt-oss-20b:** conversational exercise interpretation, contextual explanations, program and plan-builder recommendations, and 4-week plan generation. Structured output is checked against allowed exercise and program IDs; plan generation uses a JSON schema whose exercise IDs are an enum of eligible library exercises. Only relevant catalog entries are sent per chat request to stay within rate limits. The model never initiates payment, sets prices, or grants access.
- **PayPal Orders v2 sandbox:** seller authentication, user-approved order flow, capture verification, safe retry identifiers, and an actual persistent unlock. No real money is charged.
- **Supabase Auth/PostgreSQL:** email accounts, identity verification, purchases, and account-specific access policies. Service-only database functions reserve checkout and atomically complete verified purchases.
- **React Native, Expo SDK 58, TypeScript:** mobile interface and a web test surface.
- **Python/FastAPI:** business logic, provider integrations, validation, limits, and protected content.
- **Wikimedia Commons / Workout Guide:** credited demonstrations; **YouTube Data API/player:** optional video fallback. Media comes from existing sources, with core GIFs bundled; it is not generated by the LLM.

## What we built and tested

The implementation includes account sessions, chat, demonstration playback, a program recommendation/review, sandbox checkout, capture verification, purchase history, and persistent access. Automated tests cover payment validation, rejected purchases, interrupted retries, context handling, and request limits. An opt-in live Supabase test verifies concurrent reservations, account isolation, denied client writes, and idempotent completion.

## Current limits

The library has 302 exercises in 12 themed collections; 294 use draft instructions written for this prototype and illustration frames loaded from a CDN. AI-built plans repeat the same weekly sessions with progressive guidance and are not professionally reviewed. AI and external videos can be incorrect. Only the squat GIF currently supports server-side speed transformation. Progress tracking is not offered. Password recovery needs configured web redirects. Payments remain sandbox-only; production refunds, reversal webhooks, and real-commerce operations are not claimed. The rate limiter is intended for a single-worker demo.
